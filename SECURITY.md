# Security Policy

## Reporting Security Vulnerabilities

We take security seriously at **Smoke Detector**. If you discover a security vulnerability in this project, please report it to us responsibly rather than opening a public issue.

### How to Report

Please email security reports to **security@smokedetector.io**.

Include as much of the following information as possible:
- Description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept script to reproduce the issue.
- Any suggested mitigations or patches.

### Scope

- Django API endpoints (`/api/`)
- Telemetry ingestion & DSN key authentication
- Telemetry data privacy (ensuring payload data is never captured)
